## What is MindLens?

MindLens is an AI-native operating system for building, understanding, and orchestrating autonomous AI workspaces.

Think of it as a **holding company where AI agents are the employees**.

Each workspace has its own knowledge base, agent swarm, and code repos. You interact via **Telegram** using natural language.

## Why MindLens?

As AI systems become more autonomous, the challenge shifts from building individual models to organizing and understanding communities of intelligent systems.

MindLens explores this future:
- How do AI agents collaborate?
- How should autonomous organizations be structured?
- How can we understand artificial minds?

## Quick Start

```bash
pip install mindlens
```

```bash
# Configure
cp .env.example .env
nano .env
```

```bash
# Run
mindlens
```

You need:
- **OpenRouter API key** — https://openrouter.ai/keys
- **Telegram bot token** — @BotFather
- **Your Telegram user ID** — @userinfobot
